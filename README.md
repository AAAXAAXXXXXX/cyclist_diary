# Щоденник велосипедиста · Лабораторна №3

Базові екрани Flutter за дизайном лабораторної №2, без бізнес-логіки.

## Запуск

```sh
flutter pub get
flutter run -d macos
```

## Відповідність завданню

- Пункт 3.1: форми входу, реєстрації та запиту відновлення пароля через електронну пошту.
- Пункт 3.2: профіль та форма зміни пароля.
- Пункт 3.3: головний екран зі статичними даними та кнопками доступу до розділів. Самі розділи ще не реалізовані.
- Пункт 4: кнопка входу відкриває головний екран без перевірки облікового запису. Сервер, база даних, надсилання листів та збереження змін відсутні.
- Пункт 5: повторно використовувані кнопка, поле та картка винесені в `lib/core/widgets/diary_widgets.dart`.

## Структура коду

- `lib/main.dart` – запуск, перехід після входу.
- `lib/core/theme/diary_theme.dart` – кольори й оформлення.
- `lib/core/widgets/diary_widgets.dart` – спільні віджети.
- `lib/features/auth/auth_screen.dart` – вхід, реєстрація, відновлення пароля.
- `lib/features/home/home_screen.dart` – головний екран і меню.
- `lib/features/profile/profile_screen.dart` – профіль і зміна пароля.

## Перевірка

```sh
flutter analyze
flutter test
```

Для завершення лабораторної потрібні віддалений Git-репозиторій та звіт із його посиланням, скриншотами екранів і структури проєкту, прикладами коду входу, головного екрана та одного-двох спільних віджетів.
